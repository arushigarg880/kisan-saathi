# Kisan Saathi (किसान साथी) — 33 Mobile Screen Prompts for Google Stitch

Below are the 33 production-ready UI design prompts crafted from `prd.md` for the Kisan Saathi mobile app. Each prompt enforces:
1. **Mobile-First Form Factor**: Compact, touch-friendly 390×844 layout with bottom navigation or floating actions.
2. **Balanced Visuals & Concise Copy**: High visual clarity, imagery cards, status badges, iconography, avoiding long blocks of text.
3. **Multilingual & Farmer-Friendly Terminology**: Natural Hindi/English pairing (e.g. *फसल जांच / Scan Crop*, *आज क्या करें? / What to do today?*), avoiding technical machine-learning jargon.
4. **Google Stitch Optimization**: Specific layout descriptions, color palettes (earthy greens `#2E7D32`, warm ambers `#F57C00`, soft neutral cards `#F9FBE7`), and functional component structures.
